## AI Subscription Manager
AI Subscription Manager is a Java-based project that manages different AI subscription plans (e.g., Personal Plan, Pro Plan). It allows users to add, remove, and display subscription details, handle prompts, and manage team slots for collaborative usage.



## Features
- Add and remove subscription plans
- Manage prompts with quota limits
- Handle team slots for Pro Plan
- Display subscription details (model name, price, parameters, context window)
- Export and load subscription plans from files



## Tech Stack
- Java (OOP concepts: inheritance, overriding, encapsulation)
- File handling for saving/loading plans
- Flowcharts and algorithms for design
